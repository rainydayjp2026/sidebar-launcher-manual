01

スマホ風webランチャー とは？

Chromeのサイドパネルに常駐するサービスランチャーです。Gmail、Googleドライブ、ChatGPTなどよく使うウェブサービスをアイコンで管理し、ワンクリックで素早くアクセスできます。

📁 グループで整理
💤 スリープでメモリ節約
↕️ ドラッグで並び替え
💻 Windows / Mac 対応
02

インストール方法

まずもらったZIPファイルを解凍してください。
解凍すると sidebar-launcher フォルダが出てきます。

  1. Chromeを開き、アドレスバーに chrome://extensions と入力してEnter
  2. 右上の「デベロッパーモード」をオン（トグルをクリック）
  3. 「パッケージ化されていない拡張機能を読み込む」をクリック
  4. 解凍した sidebar-launcher フォルダを選択して「フォルダーの選択」
  1. Chromeを開き、アドレスバーに chrome://extensions と入力してEnter
  2. 右上の「デベロッパーモード」をオン（トグルをクリック）
  3. 「パッケージ化されていない拡張機能を読み込む」をクリック
  4. 解凍した sidebar-launcher フォルダを選択して「開く」

インストール完了後

  1. Chrome右上の拡張機能アイコン（🧩パズルのピース）をクリック
  2. 「スマホ風webランチャー」のピンアイコンをクリックしてピン留め
  3. ツールバーのアイコンをクリックするとサイドパネルが開きます
03

基本的な使い方

🚀 サービスを開く
アイコンをクリックするだけ！
  • タブが開いていない → 新しいタブで開く
  • すでにタブが開いている → そのタブに切り替える
  • スリープ中 → 「起動する」確認画面が出る
➕ 今開いているタブを追加する
下部の「現在のタブを追加」ボタンを押すと、今見ているページが自動でサービスとして登録されます。
✏️ サービスを手動で追加する
  1. グループの「＋」ボタンをクリック
  2. 名前とURLを入力して「保存」（アイコンは自動取得）
🔧 サービスを編集・削除する
サービスのアイコンを右クリック → 「編集」または「削除」
↕️ 並び替え
アイコンをドラッグして好きな位置に移動できます。別のグループにもドラッグで移動できます。
04

グループ管理

📁 グループを追加する
下部の「＋ グループを追加」ボタンをクリック
🔽 グループを折りたたむ
グループ名をクリックすると折りたたみ／展開できます
↕️ グループの順番を変える
グループヘッダー部分をドラッグして並び替えられます
✏️ グループ名変更・削除
グループヘッダーを右クリック → 「グループ名を変更」または「削除」
⚠️ グループを削除すると、グループ内のサービスもすべて削除されます
05

スリープ機能

一定時間使わなかったタブを自動的に休止させてメモリを節約できます。

⚙️ スリープを設定する
  1. サービスを右クリック → 「編集」
  2. 「スリープ」トグルをオン
  3. スリープまでの時間（分）を入力（デフォルト：30分）
  4. 「保存」
💤 スリープ中のサービスを起動する
  1. グレーアウトされたアイコン（💤マーク付き）をクリック
  2. 「起動する」をクリック
06

サイドパネルを閉じる

サイドパネル右端中央の 「›」タブ にマウスを乗せると「閉じる」と表示されます。クリックするとサイドパネルが閉じます。

07

困ったときは

Q アイコンが表示されない
→ URLが正しく入力されているか確認してください（https:// から始まるURL）
Q 拡張機能を更新したい
→ chrome://extensions を開いて更新ボタン（↺）を押してください
Q 設定をリセットしたい
→ chrome://extensions でSideBar Launcherを削除して再インストールしてください

注意事項

🔒 データはChromeにローカル保存されます（外部サーバーへの送信はありません）
ℹ️ デベロッパーモードを有効にした状態で使います。Chrome起動時に警告が出ることがありますが正常です
